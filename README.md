# The Halden

Website for a fictional pre-construction condo tower on Biscayne Bay in Miami. Buyers choose a residence and adjust its layout step by step, or draw their own, with a live plan, 3D view, sunlight and price.

## Stack

Next.js, TypeScript, Tailwind CSS, Three.js with React Three Fiber, Vitest, Playwright

## Run locally

```bash
npm install
npm run dev
```

Set `NEXT_PUBLIC_SITE_URL` (see `.env.example`) for absolute URLs in metadata and the sitemap.
